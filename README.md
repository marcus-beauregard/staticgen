# staticgen

[![CI](https://github.com/marcus-beauregard/staticgen/actions/workflows/ci.yml/badge.svg)](https://github.com/marcus-beauregard/staticgen/actions/workflows/ci.yml) [![License: GPL-2.0-or-later](https://img.shields.io/badge/license-GPL--2.0--or--later-blue.svg)](LICENSE)

A no-dependency static site generator in Python. Converts a folder of markdown
posts into HTML using a simple template. A weekend project to understand how
tools like Jekyll and Hugo work under the hood.

## Contributing

Humans and automated agents are both welcome. There is no CLA — every commit carries a [DCO](https://developercertificate.org/) sign-off (**git commit -s**). Start with a [good first issue](https://github.com/marcus-beauregard/staticgen/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) or read [CONTRIBUTING.md](CONTRIBUTING.md).
